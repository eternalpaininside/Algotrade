## Используемые технологии

---

- <b>Golang</b>: основной серверный язык
- <b>C++</b>: язык для сложных вычислений
- <b>Node.js</b>: основной фреймворк для веб-интерфейсов
- <b>PostgreSQL</b>: используемая СУБД
- <b>gRPC</b>: протокол общения между Go и C++ модулями
- <b>HTTP</b>: протокол общения между серверной частью и веб-интерфейсом

```text
Algotrade/
├── backend/             # Go: API и основная логика

│   └── Dockerfile
├── infrastructure/      # Инструменты
├── proto/               # Контракты gRPC
├── migrations/          # Миграции PostgreSQL
├── docs/                # Документация

│   └── workflows/       # Автоматические проверки
```
